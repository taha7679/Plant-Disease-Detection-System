# Plant Disease Recognition System

## 📌 Project Title
Plant Disease Recognition System



## 📖 Description
This project uses a trained Convolutional Neural Network (CNN) model to detect plant diseases from uploaded leaf images using TensorFlow and Streamlit. It classifies plant leaf images into different disease categories and provides treatment suggestions through a simple and user-friendly web interface.



## 🚀 Features
 Built using TensorFlow and Streamlit
 Classifies **38 different plant disease classes**
 Provides treatment suggestions
 Clean and user-friendly interface
 Background banner for enhanced UI

---

## 🛠️ Tech Stack
- Python
- TensorFlow
- Streamlit

---

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd plant-disease-recognition
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:
   ```bash
   streamlit run main1.py
   ```

---

## ▶️ Usage

1. Launch the Streamlit application.
2. Upload a plant leaf image.
3. The model predicts the disease category.
4. View the predicted disease and suggested treatment.
